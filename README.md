# SPOT4

SPOT4 is a DJ lighting controller for four STAGE EVOLUTION MINI SPOT 30 moving heads. You play it from an AKAI APC mini mk2, and it sends DMX through an FTDI-type USB-DMX interface (the Open DMX type).

## 起動

```
cargo run --release          # 開発中
./scripts/build-mac.sh       # dist/mac/SPOT4.app を作る
cargo test --release         # テスト
```

- APC mini mk2 は挿せば自動でつながります(2秒ごとに探す)。
- USB-DMX は上の帯でポート(`/dev/cu.usbserial-…`)を選びます。選んだポートは保存されます。
- 設定の保存先: `~/Library/Application Support/spot4/settings.json`(Windows: `%APPDATA%\spot4\`)

## 本体の設定

| メニュー | 設定 |
|---|---|
| Addr | A001 / A010 / A019 / A028(アプリの「機材の設定」と同じにする) |
| CHnd | 9CH(11CHにした場合は、アプリ側も11chにする) |
| 動作 | DMXモード |

## APC mini mk2 の配置

パッドは上の段から順に、次のとおりです。

| 段 | 左 ← → 右 |
|---|---|
| 1 | 動き: 止める / 円 / 8の字 / 左右 / 上下 / クロス / ランダム / ウェーブ |
| 2 | 1周の長さ: 4小節 / 2小節 / 1小節 / 2拍 / 1拍 ・ 揃える / ずらす / 左右対称 |
| 3 | 色: 白 / 赤 / 緑 / 青 / 黄 / 水色 / オレンジ / マゼンタ |
| 4 | 色の変え方: 固定 / 拍ごと / 小節ごと / バラバラ / レインボー ・ 位置: 客席 / 天井 / 床 |
| 5 | ゴボ: オープン / ゴボ1〜7 |
| 6 | ゴボの変え方: 固定 / 拍ごと / 小節ごと / シェイク / 回転 ・ (空き) / 動き停止 / オート |
| 7 | 明るさ: 点灯 / パルス / チェイス / 交互 / ランダム光 / 明暗の波 / チェイス×2 / ビルド |
| 8 | フラッシュ / ストロボ / ストロボ速 (この3つは押している間だけ) / 暗転 / TAP / 1拍目 / BPM÷2 / BPM×2 |

- 右の列(シーン1〜8): 押すと呼び出します。SHIFT を押しながら押すと、今の見た目を保存します。
- 下の段(トラックボタン1〜4): 1〜4台目のオン/オフを切り替えます。トラックボタン8は拍に合わせて点滅します。
- フェーダー: 動きの大きさ / Pan位置 / Tilt位置 / モーター速度 / 効果の深さ / ストロボ速度 / 回転速度 / 減衰 / マスター
- オート: 16小節ごとに見た目がランダムに変わります。
- キーボード: Space = TAP、F = フラッシュ、S = ストロボ、B = 暗転

## 安全のため

- 動作モードch(8ch)とリセットch(9ch)には常に0を送ります。つまり、本体のリセットや内蔵プログラムが勝手に動くことはありません。
- アプリを終了するときは、全チャンネルに0を送って消灯します。
