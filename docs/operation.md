# 本番での操作

## APC mini mk2 で操作する

おすすめ配置にしたときの並びです。MIDIタブの図にも同じものが出ます。右の列の5番目のボタンで、演出の1ページ目と設定の2ページ目を切り替えます。

**1ページ目: 演出**

| 場所 | 中身 |
|---|---|
| パッド 1〜4段 | LEDバーの模様。上から チル / グルーヴ / ピーク / モノクロ で、各8種類 |
| パッド 5段 | ムービングの動きの形: 止める / 円 / 8の字 / 左右 / 前後 / クロス / ランダム / ウェーブ |
| パッド 6段 | ムービングの見た目: 点灯チェイス・ランダム点灯・ブレス・ゴボ切替・ゴボ回転・ゴボシェイク・カラー回転・点灯 |
| パッド 7段 | その他の機材: Twinkle Ball、レーザーの回転・ズーム・描画・7色 |
| パッド 8段 | 押している間だけ: フラッシュ白 / フラッシュ色 / ストロボ / 入れ替え / 消灯 |
| 右の列 | TAP / 頭出し / メイン⇄サブ / 自動入れ替え / ページ切替 / グラデーション / 暗転フェード / BLACKOUT |
| 下の列 | 機種ごとのミュート: LEDバー・ムービング・その他・レーザー |
| フェーダー | LEDバーの明るさ・速さ・斜め / 機種ごとの明るさ / メイン色・サブ色の色相 / 右端は全体光量 |

**2ページ目: 設定**

色の系統をメインにするかサブにするか、1台ずつの系統、**動きの1周の長さ・揃え方**、レーザーのARM、NDI・テンポの元、入れ替えの間隔を選びます。フェーダーはムービングの動きの速さと **動きの大きさ** です。

## キーボードで操作する

MIDIコントローラーが無いときは、パソコンのキーボードで操作します。「キーボード」タブに、実際のキーの並びと同じ絵が出ます。キーの上に割り当てが書いてあり、今効いているものが光ります。絵をクリックしても押せます。
段ごとに種類をそろえてあるので、絵を見ればすぐ分かります。

| 段 | キー | 操作 |
|---|---|---|
| 数字 | 1〜8 / 9 / 0 | 今のセットのLEDバーの模様 / 前のセット / 次のセット。セットは チル→グルーヴ→ピーク→モノクロ の順 |
| QWERTY | Q〜I / O / P | ムービングの動きの形: 止める・円・8の字・左右・前後・クロス・ランダム・ウェーブ / 動きを小さく / 大きく |
| ASDF | A〜G / H〜K / L / ; | 1周の長さ: 4小節・2小節・1小節・2拍・1拍 / 揃える・ずらす・左右対称 / ゴボ回転 / カラー回転 |
| ZXCV | Z X C / V B N / M , . / | 押している間だけ: フラッシュ白・フラッシュ色・ストロボ / メイン⇄サブ・自動入れ替え・暗転フェード / 向き: 真上・扇形・交差・客席 |

**Shiftを押しながらだと色の段になります。** Shiftを押している間は、絵も色の段に変わります。「色の段 Shift」ボタンで出したままにもできます。

| 段 | キー | 操作 |
|---|---|---|
| 数字 | Shift+1〜0 | メイン色: 赤・オレンジ・黄・緑・水色・青・紫・マゼンタ・ピンク・白 |
| QWERTY | Shift+Q〜P | サブ色。並びはメイン色と同じ |
| ASDF | Shift+A〜K | メイン⇄サブ・自動入れ替え・グラデーション / 入れ替えの間隔 1・2・4・8・16拍 |
| ZXCV | Shift+Z〜C | 色の系統: 全部メイン・全部サブ・LEDバー1本おき |

- 色のキーは、その色で塗ってあります。今のメイン色・サブ色のキーは白い枠で光ります
- キーボードタブの右下に、BPMとメイン色・サブ色のプレビューが出ます

決まったキー:

| キー | 操作 |
|---|---|
| Space | タップテンポ (TAP) |
| Enter | 頭出し |
| ← → | APCのページを前・次へ |
| Esc | ブラックアウト ON/OFF |
| ⌘S / Ctrl+S | 保存 |

- キーボードの割り当ては、マップの「配置」→おすすめ配置で作られます。まだ無いときは、キーボードタブの「キーボードの配置を作る」でも作れます。こちらはAPCの割り当てを変えません
- 割り当ては「MIDI設定」の割り当て一覧で「キー Q」のように表示され、ほかの割り当てと同じように変えられます
- 名前の欄などで文字を入力している間は、Esc と ⌘S 以外は効きません
- 日本語入力がONのままでも、キーの位置で判定するので効きます
- キーを押したまま別のウィンドウへ移ったときは、押していたキーを全部離したことにします。フラッシュが残ることはありません

## ムービングの動き

ムービングライトの動きを「形」「1周の長さ」「揃え方」「向き」に分けて、別々のボタンで組み合わせます。たとえば「円 × 2拍 × 左右対称」のようにします。SPOT4 と同じ考え方です。

- **形**: 止める / 円 / 8の字 / 左右 / 前後 / クロス / ランダム / ウェーブ。クロスは隣どうしが逆に振れ、ウェーブは前後の波が左から右へ流れます。APCの1ページ目5段目、キーボードのQWERTYの段にあります
- **1周の長さ**: 4小節 / 2小節 / 1小節 / 2拍 / 1拍
- **揃え方**: 揃える / ずらす / 左右対称。ずらすは台ごとに少し遅らせます。1周の長さと揃え方は、APCの2ページ目4段目、キーボードのASDFの段にあります
- **向き**: 真上 / 扇形 / 交差 / 客席。扇形は外向き、交差は内向きです。もう一度押すと外れて、位置プリセットなどで決めたパン/チルトの今の値を中心に動きます。キーボードでは M , . / です
- **大きさ**: APCの2ページ目のフェーダー、キーボードの O / P、キーボードタブのスライダーで変えます
- 動かすのは、パン/チルトのある機材です。レーザーは除きます。並びはパッチの順で、左からです
- 床置きのムービングを「真上からどちらへ何度傾けるか」で計算するので、真上を通る動きでもパンが急に半回転しません
- 最初に1回、キーボードタブの「向き合わせ」で「真上のTilt」「正面のPan」を合わせてください。SPOT4 と同じ手順です
- パン/チルトを動かすエフェクトや位置プリセットを使うと、そちらが優先されます。このとき形は「止める」になり、向きは外れます

### 4点の動き

動きの形を **4点** にすると、決めておいた4つの向きを 1→2→3→4 の順に拍で移っていきます。1周で4つなので、1周を「1小節」にすれば1拍ごと、「2小節」なら2拍ごとに移ります。

- 向きは、キーボードタブの「4点の動き」で決めます。図の点をドラッグするか、右へ何度・客席側へ何度かを数値で入れます。位置プリセットやフェーダーでムービングを向けてから「今の向き」を押すと、左端のムービングが今向いている向きがその点になります。合わせる前に、動きを「止める」にしてください
- **移る時間**: 1つの向きにいる時間のうち、次の向きへ動くのにかける割合です。0 なら拍で一瞬で移り、100% なら止まらずに動き続けます。どちらでも、次の拍ちょうどに次の向きへ着きます。割り当ての編集で「4点の移る時間」を選べば、MIDIのフェーダーにも割り当てられます
- 揃え方: 揃えるは全台が同じ向き、ずらすは台ごとに1つ先の向きです。4台なら4つの向きに散らばって回ります。左右対称は右半分の左右が逆になります
- オートのプリセットでも、フレーズの「動き」に「4点」を選べます
- APC・キーボードのおすすめ配置のパッドには入っておらず、8つの形のままです。使うときは、画面・オートのプリセット・割り当ての編集で選びます

## レーザー

レーザーは誤操作で客席に向かないよう、ほかの機材と分けて扱います。

- **レーザー** タブで、位置と大きさを **マウスだけ** で合わせます。MIDIのフェーダーやパッドには位置を置きません。四角いパッドをドラッグすると位置を、「範囲を変更」を押してからドラッグすると **動いてよい範囲** を決められます
- 動いてよい範囲は保存され、エフェクト・シーン・MIDIのどれで動かしても、出力の直前に必ずこの中に収めます
- **オートモード・サウンドモードには絶対に入りません。** 機材定義の `forbid` で禁止した値は、出力の直前に必ず直します。内蔵の定義を上書きしても、禁止は引き継ぎます。パン/チルトの自動の動きの値も禁止しています
- **起動のたびに SAFE になり、レーザーは出ません。** ARMしたときだけ出力します。ARMの状態は保存しません
- BLACKOUT・ミュート・暗転しきったときは、レーザーOFFの値を送ります
- アプリが落ちたとき、Ctrl+C などの終了のシグナルを受けたとき、**PCのシャットダウンやログオフ**のときは、レーザーOFF・明るさ0の安全な値を約0.3秒送ってから止まります。kill -9 での強制終了・電源断・USBを抜いたときは送れないので、機材側の「信号が切れたときの動作」に頼ります
- これらは補助です。実機のキースイッチ・インターロックの代わりにはなりません
