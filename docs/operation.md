# 本番での操作

## APC mini mk2 で操作する

おすすめ配置にしたときの配列です。MIDIタブの図にも同じ内容が表示されます。右の列の5番目のボタンで、演出の1ページ目と設定の2ページ目を切り替えます。

**1ページ目: 演出**

| 場所 | 内容 |
|---|---|
| パッド 1〜4段 | LEDバーの模様。上から チル / グルーヴ / ピーク / モノクロ で、各8種類 |
| パッド 5段 | ムービングの動きの形: 停止 / 円 / 8の字 / 左右 / 前後 / クロス / ランダム / ウェーブ |
| パッド 6段 | ムービングの見た目: 点灯チェイス・ランダム点灯・ブレス・ゴボ切替・ゴボ回転・ゴボシェイク・カラー回転・点灯 |
| パッド 7段 | その他の機材: Twinkle Ball、レーザーの回転・ズーム・描画・7色 |
| パッド 8段 | 押下中のみ: フラッシュ白 / フラッシュ色 / ストロボ / 入れ替え / 消灯 |
| 右の列 | TAP / 頭出し / メイン⇄サブ / 自動入れ替え / ページ切替 / グラデーション / 暗転フェード / BLACKOUT |
| 下の列 | 機種ごとのミュート: LEDバー・ムービング・その他・レーザー |
| フェーダー | LEDバーの明るさ・速さ・斜め / 機種ごとの明るさ / メイン色・サブ色の色相 / 右端は全体光量 |

**2ページ目: 設定**

色の系統をメインにするかサブにするか、1台ずつの系統、**動きの1周の長さ・揃え方**、レーザーの ARM、NDI・テンポの元、入れ替えの間隔を選択します。フェーダーはムービングの動きの速さと **動きの大きさ** です。

## キーボードで操作する

MIDIコントローラーが無いときは、パソコンのキーボードで操作します。「キーボード」タブにキー配列の図が表示され、各キーに割り当てが記載されます。有効なキーは点灯し、図のクリックでも操作できます。
段ごとに種類を揃えてあるため、図を見ればすぐ把握できます。

| 段 | キー | 操作 |
|---|---|---|
| 数字 | 1〜8 / 9 / 0 | 現在のセットの LED バーの模様 / 前のセット / 次のセット。セットは チル→グルーヴ→ピーク→モノクロ の順 |
| QWERTY | Q〜I / O / P | ムービングの動きの形: 停止・円・8の字・左右・前後・クロス・ランダム・ウェーブ / 動きを小さく / 大きく |
| ASDF | A〜G / H〜K / L / ; | 1周の長さ: 4小節・2小節・1小節・2拍・1拍 / 揃える・ずらす・左右対称 / ゴボ回転 / カラー回転 |
| ZXCV | Z X C / V B N / M , . / | 押下中のみ: フラッシュ白・フラッシュ色・ストロボ / メイン⇄サブ・自動入れ替え・暗転フェード / 向き: 真上・扇形・交差・客席 |

**Shift を押しながらだと色の段になります。** Shift を押している間は、絵も色の段に変わります。「色の段 Shift」ボタンで表示したままにもできます。

| 段 | キー | 操作 |
|---|---|---|
| 数字 | Shift+1〜0 | メイン色: 赤・オレンジ・黄・緑・水色・青・紫・マゼンタ・ピンク・白 |
| QWERTY | Shift+Q〜P | サブ色。並びはメイン色と同じ |
| ASDF | Shift+A〜K | メイン⇄サブ・自動入れ替え・グラデーション / 入れ替えの間隔 1・2・4・8・16拍 |
| ZXCV | Shift+Z〜C | 色の系統: 全部メイン・全部サブ・LEDバー1本おき |

- 色のキーは、その色で塗装されています。現在のメイン色・サブ色のキーは白い枠で点灯します
- キーボードタブの右下に、BPMとメイン色・サブ色のプレビューが表示されます

固定のキー:

| キー | 操作 |
|---|---|
| Space | タップテンポ (TAP) |
| Enter | 頭出し |
| ← → | APC のページを前・次へ |
| Esc | ブラックアウト ON/OFF |
| ⌘S / Ctrl+S | 保存 |

- キーボードの割り当ては、マップの「配置」→おすすめ配置で作成されます。まだ無いときは、キーボードタブの「キーボードの配置を作る」でも作成できます。こちらは APC の割り当てを変更しません
- 割り当ては「MIDI設定」の割り当て一覧で「キー Q」のように表示され、他の割り当てと同様に変更できます
- 名前の欄などで文字を入力している間は、Esc と ⌘S 以外は効きません
- 日本語入力が ON のままでも、キーの位置で判定するため有効です
- キーを押したまま別のウィンドウへ移ると、すべてのキーを解放した扱いになり、フラッシュが押しっぱなしになりません

## ムービングの動き

ムービングライトの動きを「形」「1周の長さ」「揃え方」「向き」に分けて、別々のボタンで組み合わせます。たとえば「円 × 2拍 × 左右対称」のように設定します。SPOT4 と同じ考え方です。

- **形**: 停止 / 円 / 8の字 / 左右 / 前後 / クロス / ランダム / ウェーブ。クロスは隣どうしが逆に振れ、ウェーブは前後の波が左から右へ流れます。APC の1ページ目5段目、キーボードの QWERTY の段にあります
- **1周の長さ**: 4小節 / 2小節 / 1小節 / 2拍 / 1拍
- **揃え方**: 揃える / ずらす / 左右対称。ずらすは台ごとに少し遅らせます。1周の長さと揃え方は、APC の2ページ目4段目、キーボードの ASDF の段にあります
- **向き**: 真上 / 扇形 / 交差 / 客席。扇形は外向き、交差は内向きです。もう一度押すと解除され、位置プリセットなどで決めたパン/チルトの現在の値を中心に動きます。キーボードでは M , . / です
- **大きさ**: APC の2ページ目のフェーダー、キーボードの O / P、キーボードタブのスライダーで変更します
- 動かすのは、パン/チルトのある機材です。レーザーは除きます。並びはパッチの順で、左からです
- 床置きを基準に「真上からどちらへ何度傾けるか」で計算するため、真上を通過してもパンが急に半回転しません
- 最初に1回、キーボードタブの「向き合わせ」で「真上のTilt」「正面のPan」を合わせてください。SPOT4 と同じ手順です
- パン/チルトを動かすエフェクトや位置プリセットを使用すると、そちらが優先されます。このとき形は「停止」になり、向きは解除されます

### 4点の動き

動きの形を **4点** にすると、設定しておいた4つの向きを 1→2→3→4 の順に拍で移動します。1周で4つのため、1周を「1小節」にすれば1拍ごと、「2小節」なら2拍ごとに移動します。

- 向きは、キーボードタブの「4点の動き」で設定します。図の点をドラッグするか、右へ何度・客席側へ何度かを数値で入力します。位置プリセットやフェーダーでムービングを向けてから「今の向き」を押すと、左端の機材の向きを取り込めます。取り込む前に、動きを「停止」にしてください
- **移動時間**: 1つの向きにいる時間のうち、次の向きへ動くのにかける割合です。0% なら拍で一瞬で移動し、100% なら停止せずに動き続けます。どちらの場合も、次の拍ちょうどに次の向きへ到達します。割り当ての編集で「4点の移る時間」を選択すれば、MIDI のフェーダーにも割り当てられます
- 揃え方: 揃えるは全台が同じ向き、ずらすは台ごとに1つ先の向きです。4台なら4つの向きに分散して回ります。左右対称は右半分の左右が逆になります
- オートのプリセットでも、フレーズの「動き」に「4点」を選択できます
- APC・キーボードのおすすめ配置のパッドには含まれておらず、8つの形のままです。利用するときは、画面・オートのプリセット・割り当ての編集で選択します

## レーザー

レーザーは誤操作で客席に向かないよう、他の機材と分けて扱います。

- **レーザー** タブで、位置と大きさを **マウスだけ** で合わせます。MIDI のフェーダーやパッドには位置を置きません。四角いパッドをドラッグすると位置を、「範囲を変更」を押してからドラッグすると **動いてよい範囲** を設定できます
- 動いてよい範囲は保存され、エフェクト・シーン・MIDI のどれで動かしても、出力の直前に必ずこの範囲内に収めます
- **オートモード・サウンドモードには一切入りません。** 機材定義の `forbid` で禁止した値は、出力の直前に必ず補正します。内蔵の定義を上書きしても、禁止は引き継がれます。パン/チルトの自動の動きの値も禁止しています
- **起動のたびに SAFE となり、レーザーは出力されません。** ARM したときだけ出力します。ARM の状態は保存しません
- BLACKOUT・ミュート・暗転しきったときは、レーザーOFF の値を送信します
- クラッシュ時や終了シグナル受信時、**PC のシャットダウン・ログオフ時** は、レーザーOFF・明るさ0の安全な値を約0.3秒送信してから停止します。kill -9 による強制終了・電源断・USB の抜去時は送信できないため、機材側の「信号が切れたときの動作」に依存します
- これらは補助的な機能です。実機のキースイッチ・インターロックの代わりにはなりません
