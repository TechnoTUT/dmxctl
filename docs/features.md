# 機能の詳しい説明

画面のボタンやメニューの名前は「」で示します。名前に括弧が含まれるものは、画面の表示のままです。

## MIDIタブのマップ

「MIDI」タブは、APC mini mk2 の実機と同じ配置の図です。この説明では「マップ」と呼びます。

- 配列は、パッド 8×8 が Note 0x00〜0x3F で左下が 0x00、シーンボタンが上から 0x70〜0x77、トラックボタンが 0x64〜0x6B、SHIFT が 0x7A、フェーダー 9本が CC 0x30〜0x38 で右端がマスターです
- 割り当て済みのコントロールは、動作の種類で色分けして内容を表示します。青はチャンネル値、緑はシーン、紫はエフェクト、赤はブラックアウトです。空のパッドには Note 番号を表示します
- 押下中は明るく点灯し、フェーダーは現在の位置をバーで表示します。エフェクトやトグルが ON の間も明るくなります
- クリックすると右の編集パネルが開き、その場で割り当ての作成・変更・削除・MIDI ラーンができます
- 配置と番号は `src/core/io/apcmini.rs` にあり、AKAI 公式の Communications Protocol v1.0 に基づいています。初期状態の Session View で、チャンネル1のメッセージが対象です

### 今の色

マップの上に、各機材が **現在実際に出力している色** を並べて表示します。DMX の出力値から読み取るため、全体光量・ブラックアウト・エフェクト・チェイス・ピクセルエフェクト・フラッシュがすべて反映されます。

- 1色の機材は色見本で表示します。暗いほどディマーや全体光量が低く、消灯しているときは斜線です。カラーホイールの色は、機材定義で範囲に付けた名前か、指定した色で表示します。判別できない色は「?」です
- LEDバーは、ピクセルごとの色の帯で表示します
- ARM していないレーザーは「SAFE」、ブラックアウト中は「BLACKOUT」と表示されます
- 右側に、現在のメイン色とサブ色が表示されます。入れ替え中はその旨も表示されます
- マウスを乗せると、色の名前と明るさを % で表示します
- エフェクトなどで色が自動的に変化している間は、マップを1秒に4回更新します。ウィンドウが前面のときに限ります

### フェーダーの連動

- 実機のフェーダーを動かすと、図のフェーダーのバーと白いつまみがリアルタイムに追従します
- 接続した瞬間に、APC mini mk2 へ SysEx の Introduction Message を送信して9本の現在の位置を読み取るため、操作前から正しい位置が表示されます。「フェーダー位置を読み取る」ボタンで再読み取りできます
- 読み取った位置は**表示だけ**で、出力には反映しません。接続と同時に機材が動いたりレーザーが出力されたりするのを防ぐためで、実際に動かしたときから値が有効になります

## パッドの LED

APC mini mk2 の、割り当てのあるパッドやボタンが点灯します。接続している間のみ動作し、切断・終了のときには全部消灯します。MIDIタブの「パッドのLEDを点灯」で ON/OFF を、「待機中の明るさ」で 10% / 25% / 50% を選択できます。

**動作の種類ごとの色**

| 動作 | 色 |
|---|---|
| シーン呼出 | 緑 |
| エフェクト | 紫 |
| チェイス | 黄 |
| ペア | ピンク |
| ブラックアウト | 赤 |
| TAP などのテンポ | 水色 |
| 位置プリセット | 水色。最後に呼び出した位置が明るく点灯する |
| ページ切替 | 白。現在のページが明るく点灯し、右の列のボタンなら点滅する |
| チャンネル値 | 青。ただし、カラーなどを選択するパッドは、赤・緑・青・黄・オレンジ・白など、選択する色そのもの |

**明るさ**

- 割り当てはあるが効いていない待機中は、暗めに点灯します
- 効いている間は最大の明るさです。エフェクト ON・チェイス動作中・ペア ON・ブラックアウト中・トグル ON・現在選択されている色や値・最後に呼び出したシーンが該当します。シーンはラジオボタンのように1つだけ点灯します
- 押下中は白です
- **TAP のパッド**は拍に合わせて点滅し、小節の頭の1拍目だけオレンジになります
- 割り当てのないパッドは消灯しています

**実際の色で点灯させる**: 次のパッドは、128色のパレットから近い色を選択する代わりに、APC mini mk2 のフルカラー指定を使って **実際の RGB の色** で点灯します。仕様書の SysEx「RGB LED Color Lighting」です。待機中は暗め、選択されている色は最大の明るさです。画面のマップのパッドも同じ色で表示します。

- 色の全体制御のパッドと、メイン色・サブ色のパッドは、その色で点灯します。カラーピッカーで作成した色や、パレットに無い色もそのまま表示されます
- 「チャンネル値」でカラーホイールなどの色を選択するパッドは、機材定義でその範囲に指定した色で点灯します
- 機材選択のパッドは、**その機材が現在出力している色**で点灯します。LED バーは1番目のピクセルの色です
- メイン⇄サブ入れ替えのパッドは、現在メインの機材に出力されている色で点灯します
- 「MIDI/OSC」タブの「色のパッドは実際の色で」を OFF にすると、従来どおりパレットの近い色で点灯します。実機で色がおかしいときは OFF にしてください

**右の8つのシーンボタンと、下のトラックボタン** は単色の LED のため、割り当てがあれば点灯し、有効な間は点滅します。SHIFT とフェーダーには LED がありません。

仕組み: 通信仕様書どおり、パッドは Note On のベロシティで色、MIDI チャンネルで明るさを送信します。変化分だけを送信し、実機側のずれを補正するため3秒ごとに全パッドを再送信します。

## パッドのページ

APC mini mk2 の64パッドを、**8ページ**に分けて利用できます。たとえばページ1を色、ページ2を位置、ページ3をエフェクトに割り当てられます。

- 割り当てごとに「全ページ共通」か「ページNだけ」を選択します。現在のページの割り当てと、共通の割り当てだけが反応・点灯します
- ページは、動作「ページ切替」で ページNへ / 次へ / 前へ 切り替えます。マップの「**ページ切替を配置**」を押すと、右の列のシーンボタン1〜8を「ページ1〜8へ」にします。使用中のボタンは除外されます。マップ上部のページ番号をクリックしても切り替わり、実機も同じページになります
- マップは現在のページを表示します。ページを利用しているとき、マップで新規作成するパッドの割り当ては、表示中のページ専用になります。ボタンとフェーダーは共通です
- 既存プロジェクトの割り当ては、すべて「全ページ共通」のままです。「共通のパッド N件をページN専用にする」ボタンで、パッドの割り当てを一括で現在のページへ移動できます
- パッドを押したままページを切り替えても、離したときの処理は元の割り当てに届き、押しっぱなしになりません。フェーダーは現在のページの割り当てにだけ効きます

## 機材定義とカテゴリ

**機材定義** タブで、機材・モード・チャンネルを画面上で作成できます。保存すると、その場で配置済みの機材にも反映されます。値は機能名 `attr` で引き継がれ、追加されたチャンネルは初期値になります。

- チャンネルごとに、名前・機能名 `attr`・**カテゴリ**・初期値・安全値・16bit の下位バイト・値の範囲の選択肢を設定します
- 値の範囲に名前を付けると、コントロール画面では色やゴボのように選択式になります。「連続」は範囲内の値が速度などの意味を持つ場合に、「注意」はリセットなど誤操作を避けたい項目に使います。「N個に均等分割」で一括作成することもできます
- 「Pan/Tilt (16bit)」「RGB」「ディマー」は1クリックで追加できます。チャンネルの並べ替え・削除をしても、16bit の紐付けは自動で追随します
- 保存の前に、機能名の重複・16bit 指定の誤り・範囲の欠落や重複を検出して通知します
- 内蔵の機材を編集すると、元の定義とは別のファイルとして保存されます。「初期状態に戻す」で削除して元に戻せます

**カテゴリ**: 標準は 動き / 色 / 光量 / 形 / 制御 / その他 で、自由に追加できます。

- コントロール画面が、機材ごとにカテゴリ別にまとまります。上のボタンで表示するカテゴリを絞り込めるため、「動きだけ確認したい」ときに便利です
- シーンは「保存する項目」で絞り込んで保存できます。「動きだけ」のシーンと「色だけ」のシーンを別々に作成し、パッドで組み合わせて呼び出せます。「現在値で上書き」は、その部分シーンのまま更新します

## 全体光量

すべての機材のディマーにかかる、全体の明るさのつまみです。マスターとも呼びます。

- **初期状態では右端のフェーダーに割り当てられています。** APC mini mk2 のマスターフェーダー、CC 0x38 です。画面上部の「全体光量」スライダーでも操作できます
- マップや MIDI タブで動作「全体光量」を選択すれば、他のフェーダーやノブ、パッドにも割り当てられます。パッドなら「押下中」「トグル」などで、ON のときと OFF のときの % を指定します
- 対象は各機材の `dimmer` チャンネルです。ディマーが無い RGB 灯具などは `red / green / blue / white / amber / uv` に掛かります。Pan/Tilt・ストロボと、ディマーの無いレーザーには影響しません。元の値は変更されないため、全開に戻せば元に戻ります
- APC mini mk2 と接続した瞬間に、実機のマスターフェーダーの位置を読み取って出力も合わせます。下まで下げてあれば、暗い状態から開始します。他の割り当ては接続時には動きません
- 起動時は全開の100%です。値は保存しません。既存プロジェクトにも、一度だけ右端のフェーダーへ自動で割り当てます。削除した割り当ては復活させず、右端のフェーダーが別の用途で使われている場合は上書きしません

## BPM・チェイス

**テンポ** は全体で共通の1つです。画面上部の2段目と「BPM/チェイス」タブで操作できます。

- BPM は 20〜300 を直接入力できます
- **TAP** は、叩いた間隔の平均から BPM を決定し、拍の位置も叩いたタイミングに合わせます。2秒以上空くと数え直します
- **頭出し** は、拍の位置を小節の頭へ合わせます。÷2 / ×2 もあります
- 上部のドットが1小節の4拍を表し、1拍目はオレンジです。テンポを変更しても、拍の位置は飛ばずに連続します
- MIDI には動作「テンポ」で、TAP / 頭出し / BPM 調整 / BPM ± を割り当てられます。BPM 調整はフェーダーで最小〜最大の BPM を指定し、BPM ± はボタン1回で増減します

**エフェクトの BPM 同期**: エフェクトの「速さ」を「BPM同期: N拍で1周期」にすると、拍に合わせて動作します。拍数は 16/8/4/2/1/0.5/0.25 か、任意の数を選択できます。テンポを変更しても位相はずれません。「自由(Hz)」に戻せば従来どおりです。

**チェイス**: シーンを BPM に合わせて順番に呼び出します。

- 1ステップの長さ、フェード、順序を指定します。長さとフェードは拍で決め、フェード0はカットです。順序は 順番 / 往復 / ランダム です。フェードの秒数は BPM から計算するため、テンポを変更しても拍に対する長さは変わりません
- ランダムは、1周ごとに全ステップを一度ずつ、順番をシャッフルして出力します。同じステップは連続しません
- 「色だけ」「動きだけ」などの部分シーンを使えば、複数のチェイスを同時に動かして、色と動きを別々のテンポで回せます
- チェイスの ON/OFF は、動作「チェイス」でパッドに割り当てられます。トグル / 押下中 / ワンショット を選択できます。動作中のステップは一覧に▶で表示されます
- チェイスによる値の変化は一時的なものとして扱い、自動保存の対象にしません

## ペア

**ペア** タブで、2台の機材を組にします。「元」の機材の動きに「ペア相手」が追従し、指定した機能は反転できます。左右対称に動かしたいときに使います。

ペアを A→B→C のようにつなぐと、登録した順番によらず、A から B、B から C の順に反映します。反転や連動しない項目の設定は、各ペアで適用します。

- ペア相手は、元の機材の**最終的な値**に追従します。手動操作・エフェクト・シーン・チェイス・全体光量のどれも、元の機材に対して行えば、ペア相手にも反映されます。反転の設定があれば反転します
- **左右反転**: 反転する機能を選択します。既定は `pan` です。値は 0↔255 で反転し、16bit の Pan は 16bit の精度で反転します。レーザーのパン位置のように範囲付きの機能は、連続の範囲の中でだけ反転し、マクロなど選択式の値は変更しません
- **連動しない項目**: カテゴリ単位で除外できます。既定では「制御」を除外し、リセットなどのマクロまで連動させないようにしています
- **連動と反転は別のスイッチ**です。連動 ON で反転 OFF なら同じ動きになり、連動 OFF なら独立に戻ります。どちらも MIDI の動作「ペア」で、トグルか押下中としてパッドに割り当てられます
- 同一機種どうしなら、カラーやゴボのような選択式も連動します。機種が異なる場合は、選択式のチャンネルは値の意味が異なるため連動せず、スライダー式のチャンネルだけが同一の機能名 `attr` で対応します
- ペア相手のチャンネルは、連動している間、コントロール画面で操作できません。連動後の値を灰色で表示し、「ペア: ○○ に連動中」と表示されます。ペア相手自身の値は書き換えないため、連動を OFF にすればすぐ元に戻ります
- ペア相手に直接かけたエフェクトは、連動しているチャンネルについては元の機材の値が優先されます

## フラッシュ

動作「**フラッシュ(全開)**」をパッドに割り当てると、押下中だけ全機材を全開にします。「トグル」にもできます。

- **元の値は変更しません。** 離すとフラッシュ前の明るさと色に戻ります。「チャンネル値」の「押下中」は離すと OFF の値になるため、元の明るさに戻したいときはフラッシュを使います
- 「白で全開」を ON にすると色も白にします。OFF なら現在の色のまま全開にし、LED バーはピクセルごとの色のまま、最大の明るさにします
- 全体光量より優先します。ブラックアウト中は点灯しません。**ARM が必要なレーザーには掛かりません**
- OSC: `/dmx/flash 1/0` で白、`/dmx/flash/color 1/0` で現在の色のまま点灯します

## 暗転フェード

上部の「**暗転**」を押すと、全体の明るさを右に記載した秒数をかけて0にします。秒数の既定は3秒で、キーボードでは N です。もう一度押すと同じ秒数で戻ります。

- 全体光量と同じ箇所にかかり、元の値は変更しません。途中の明るさはボタンに % で表示されます
- 暗転しきると、ブラックアウトと同じ扱いになります。レーザーなど明るさのチャンネルが無い機材も停止し、フラッシュも効きません
- パッドには動作「**暗転フェード**」で秒数を指定して割り当てます。トグルなら押すたびに暗転と復帰を繰り返し、押下中なら離すと戻ります。暗転中はパッドが点灯します
- OSC: `/dmx/fade 1` で暗くし、`/dmx/fade 0` で戻します。2つ目の数値で秒数を指定でき、`/dmx/fade 1 8` のように送信します。`/dmx/fade/time 5` で標準の秒数を変更します

## 色の全体制御

「赤」「青」といった**色そのもの**を指定すると、機材ごとの仕組みに合わせて設定されます。機種が異なっても、1つのパッドで全体の色を揃えられます。

| 機材の種類 | 設定方法 |
|---|---|
| `red / green / blue` を持つ RGB の灯具 | その色の RGB 値。`white` がある RGBW は、共通の成分を白チャンネルに回す |
| MINI SPOT や LASER など、カラーホイール・色の範囲を持つ機材 | 「color」チャンネルの単色の範囲のうち、一番近い色。範囲の名前が赤・青・ライトブルーなどのものが対象 |
| どちらも無い機材 | 変更しない |

- ディマーの明るさには触れません。全体光量とは独立しています
- 色はシーンにも保存されます。シーンの「保存する項目」を「色」だけにすれば、色だけのシーンになります

### 全体/個別スイッチ

- **全体** では全機材に色がかかり、**個別** では選択中の機材だけにかかります。起動時は全体で、個別の初期選択は先頭の機材です
- 切り替えは、画面上部の「色: 全体/個別」ボタンか、MIDI の動作「色:全体/個別 スイッチ」で行います。動作は 押すたびに切替 / 押下中だけ個別 / 全体にする / 個別にする から選択します
- 個別モードで色をかける機材は、上部に表示される機材名のボタンで選択・解除します。複数選択できます。MIDI の動作「機材選択」で、この機材だけを選択するか、選択に追加・解除することもできます
- コントロールタブの上部に、10色の色パレットと色相スライダーがあります。操作先は上のスイッチに従います

### 色の MIDI 割り当て

動作「色(全体制御)」を使います。

- 色を選択すると、そのパッドを押した瞬間にその色になります。「色相(フェーダー)」を選択すると、フェーダーやノブで **HSV の色相 H** を連続で動かせます。詳しくは下の [色相Hのフェーダー](#色相hのフェーダー)
- 操作先は「全体/個別スイッチに従う」「常に全機材」「常に選択中の機材」から選択できます。既定は「全体/個別スイッチに従う」です
- マップの「**色の操作を配置**」ボタンで、空いている箇所にまとめて割り当てます。下段のパッド8個に赤・オレンジ・黄・緑・水色・青・紫・白、右下のシーンボタンに全体⇄個別、トラックボタン1〜8に機材の順で機材の選択、**フェーダー8に色相 H** が入ります。使用中のボタンは除外されます
- APC mini mk2 の LED は、色のパッドがその色で点灯し、最後に選択した色が明るくなります。個別モード中と、選択中の機材のボタンは点滅します

### メイン色とサブ色

機材を **メイン** と **サブ** の2系統に分けて、2つの色を出し分けます。**入れ替え**で一瞬で色を交換できます。

- **割り当て**: コントロールタブの「出す色:」で、機材ごとに メイン / サブ / 対象外 を選択します。既定はすべてメインです。同一機種が複数あるときは「機種ごと」でまとめて選択できます。たとえばスポットをメイン、レーザーをサブにすると、機種ごとに別々の色になります
- **色の決め方**:
  - 「メイン/サブ:」の色見本をクリックすると、カラーピッカーで自由に選択できます
  - 色の行の操作先を「→メイン」「→サブ」にすると、10色の色ボタンと H スライダーで、その系統の色を決定できます。「全体」に戻すと、従来どおり機材に直接かけます
- **入れ替え**: 「⇄ 入れ替え」を押すと、メインの機材にサブ色、サブの機材にメイン色が出力されます。もう一度押すと戻ります。全部メインにしておけば、「全体がメイン色」と「全体がサブ色」の切り替えになります
- **拍で自動入れ替え**: チェックを入れると、指定した拍数ごとにメインとサブが自動で入れ替わります。BPM・Link・MIDI クロックに同期します。自動入れ替えによる色の変化は、自動保存の契機にしません
- 対象外の機材は、メイン/サブの操作では色が変化しません
- **MIDI 割り当て**: 動作「色(全体制御)」の操作先に「メイン色にする」「サブ色にする」があり、色パッドにも色相フェーダーにも利用できます。動作「メイン/サブ色 入れ替え」では、押すたびに入れ替え / 押下中だけ入れ替え / 拍で自動入れ替え ON/OFF を選択できます
- マップの「**メイン/サブ色を配置**」を押すと、下から2段目のパッド8個にメイン色、3段目にサブ色、シーンボタン7に入れ替え、シーンボタン6に自動入れ替え、フェーダー6・7にメイン・サブの色相が入ります。シーンボタンが使用中ならトラックボタン8・7に配置します。他にも使用中の箇所は除外されます
- LED は、現在のメイン色・サブ色のパッドが明るく点灯し、入れ替え中・自動入れ替え中のボタンは点滅します
- OSC: `/dmx/main 赤`、`/dmx/sub blue`、`/dmx/main/hue 0.5`、`/dmx/swap`、`/dmx/swap/auto 1`
- メイン/サブの色は、色を決定したとき・入れ替えたとき・割り当てを変更したときにだけ反映されます。色パッドやシーンなど他の操作で上書きされた色は、次にメイン/サブを操作するまで維持されます

### 色相Hのフェーダー

- フェーダーの端から端までで、色相環を**0〜360°**一周します。下端の0°が赤で、60°が黄、120°が緑、180°が水色、240°が青、300°がマゼンタ、上端の360°で赤に戻ります。彩度と明度は最大で、明るさは全体光量やディマーで別に決めます
- 割り当ては、マップや MIDI タブの動作「色(全体制御)」→「色相(フェーダー)」で行います。マップの「色の操作を配置」を押すと、右から2番目のフェーダー8に自動で入ります
- 操作先は「全体/個別スイッチに従う」「常に全機材」「常に選択中の機材」から選択できます
- RGB の灯具は、その色相そのままの色になります。スポットやレーザーのようにカラーホイール・色の範囲を持つ機材は、その色相に一番近い色の範囲に切り替わるため、フェーダーを動かすと色が段階的に変化します
- マップのフェーダーは、値の代わりに**度数**を表示し、バーもその位置の色で塗ります。コントロールタブの「H」スライダーには度数と色見本が付いていて、実機のフェーダーを動かすと一緒に動きます。スライダーを直接動かしても同じ操作になります
- 接続時に読み取るフェーダーの初期位置は色相に反映せず、動かしたところから有効になります

### 範囲ごとの色

機材定義エディタの「値の範囲・選択肢」で、各範囲に**その範囲が出す色**を指定できます。「色」にチェックを入れて、カラーピッカーで選択します。レーザーやカラーホイールの「DMX のこの値はこの色」を、名前に関係なくソフトウェア内で決められます。

- 色を指定した範囲は、**表示名に関係なく**その色として扱います。「ネオンピンク」でも、「赤/緑」のような複数色の名前でも利用できます。名前が「赤」でも、指定した色が優先されます
- 「色」にチェックがない範囲は、従来どおり表示名に含まれる色の名前から判定します。判定できる名前は 赤・緑・青・黄・白・紫・オレンジ・ピンク・マゼンタ・シアン・ライトブルー です。判定できた色は見本として表示され、判定できない範囲は「色なし」と表示されて、色の全体制御と色相フェーダーの対象外になります
- 指定した色は、色の全体制御の赤・青などのパッド、色相フェーダー、パッドの LED の色、コントロールタブのドロップダウンの色見本で使われます。LED はパレットの一番近い色で点灯します
- 「色」にチェックを入れた直後は、名前から判定した色が初期値になります。判定できなければ白です
- 保存される定義ファイルには、色を指定した範囲だけ `"color": [R, G, B]` が含まれます。古い定義もそのまま読み込めます

## LED バー

DMX で **RGBRGBRGB…** とピクセルが並んでいる LED バーを扱えます。

**機材の追加**: 「パッチ」タブで内蔵の汎用機材「LEDバー (RGBピクセル)」を追加し、モードを実機のチャンネル数に合わせます。3ch は全体で1色、12ch は4ピクセルで、18ch・24ch・30ch・36ch・48ch・72ch・96ch はそれぞれ 6・8・10・12・16・24・32 ピクセルです。実機の DMX アドレスも合わせてください。

- このモードに無いピクセル数や、色の並びが **GRB / BGR / RGBW** などの機種、先頭にディマーやストロボのチャンネルがある機種は、「機材定義」タブの「まとめて追加 → RGBピクセル (LEDバー)…」で作成できます。ピクセル数と色の並びを指定し、既にピクセルがあれば続きの番号から追加します
- ピクセルのチャンネルの機能名は `red.1` `green.1` `blue.1` `red.2` … です。番号なしの `red` を指定すると全ピクセルの赤になり、MIDI 割り当て・エフェクト・OSC の `/dmx/fixture/<ID>/red` で利用できます。1ピクセルだけなら `red.3` のように指定します

**これまでの機能はそのまま有効です**

- 色ボタンや色相フェーダーによる色の全体制御
- **メイン/サブ色**。LED バーをメインかサブに割り当てます
- シーン。ピクセルごとの値を保存します
- 全体光量。ディマーの無いバーは RGB にかかります
- ブラックアウト。ピクセルは消灯します

**コントロールタブ**: LED バーは、ピクセル数ぶんのスライダーの代わりに、**現在の出力を色の帯で表示**します。エフェクトと全体光量も反映した色で、画面は操作したときと拍ごとに更新します。「全体」の色見本で全ピクセルの色を、「ピクセルごとの色」で1つずつの色を選択できます。

**ピクセルエフェクト**: 「エフェクト」タブの下にある、バーに沿って動く色の模様です。速さは BPM に同期し、1周の拍数で決めます。

| 種類 | 動き | 「幅」の意味 |
|---|---|---|
| レインボー | 色相がバーに沿って流れる | 繰り返し回数 |
| 流れる点 | 色Aの点が色Bの上を1ピクセルずつ進む | 点の幅 |
| ワイプ | 色Aで端から埋め、次に色Bで埋め戻す | - |
| 交互 | 色Aと色Bを交互に並べ、1周ごとに入れ替え | 1色の幅 |
| きらめき | 色Bの上に色Aがランダムに点灯する。1周に8回選び直す | 点灯する数 |
| グラデーション | 色A→色Bのグラデーションが流れる | 繰り返し回数 |
| 流れる縞 | 色Aと色Bの縞が1ピクセルずつ流れる。1周で縞2本分 | 縞の幅 |
| ウェーブ | 色Aと色Bがなめらかな波になって流れる | 繰り返し回数 |
| 交互ウェーブ | 隣り合う組が、色A⇄色Bを逆向きにふわっと行き来する | 1色の幅 |

- 色Aと色Bは、**メイン色 / サブ色**・消灯・白・指定の色から選択できます。メイン色・サブ色を選択すれば、入れ替えや拍での自動入れ替えにも追従します
- 「複数台を1本につなげる」を ON にすると、複数のバーをパッチの順に1本の長いバーとして流します。OFF なら各台で同じ動きをします。「逆向き」で流れる向きを反対にします
- 「中央から左右対称」を ON にすると、どの模様も中央から外へ広がる形になります
- ON/OFF は、通常のエフェクトと同様に動作「エフェクト」でパッドに割り当てます。同じ名前のものはまとめて ON/OFF します。OSC は `/dmx/effect 名前 1/0` です
- ピクセルエフェクトは出力だけを変更します。元の値は変わらないため、OFF にすれば元の色に戻ります
- **1本のバーで有効になる模様は1つだけです。** 別の模様を ON にすると、同じバーの他の模様は自動で OFF になるため、パッドでそのまま切り替えられます。別々のバーの模様は同時に動作します

**メイン/サブの模様プリセット**: 「＋ メイン/サブの模様プリセット」から、メイン色とサブ色を混ぜる模様を追加できます。追加したときは OFF です。「全部まとめて追加」もあります。

| プリセット | 内容 |
|---|---|
| 縞々 | 2ピクセルずつの縞。停止したまま |
| 縞々スクロール / 太縞スクロール | 幅2 / 幅4 の縞が、4拍 / 8拍で1周して流れる |
| 交互チェンジ | 1ピクセルおきの縞が、拍ごとに入れ替わる |
| ウェーブ / 細かいウェーブ | メインとサブの波が流れる |
| 交互ウェーブ | 隣どうしが逆向きにメイン⇄サブを行き来する |
| センターウェーブ / センター縞 | 中央から左右対称に広がる |
| グラデーション / メイン点が走る | メイン→サブのグラデーション / サブの上をメインの点が走る |

- メインとサブの色を変更したり、入れ替えや拍での自動入れ替えをしたりすると、模様の色もそのまま変化します
- マップの「**LEDバーの模様を配置**」を押すと、先頭の8種類をパッドの最上段に「トグル」で並べます。使用中のパッドは除外して、2段目までの次の空きに配置します。配置済みの模様は二重に配置しません。ページを利用しているときは表示中のページに配置します

## 位置プリセットと XY パッド

- **XY パッド**: パン/チルトのある機材には、コントロールタブの「動き」の先頭に四角いパッドが表示されます。ドラッグすると、横でパン、縦でチルトを同時に動かせます。**Shift+ドラッグ**で細かく動き、16bit の機材は下位バイトまで動きます。ペアで連動中の機材は、連動後の位置を表示するだけで動かせません
- **位置プリセット**: コントロールタブ上部の「位置:」で、現在のパン/チルトに「客席」「天井」「ミラーボール」などの名前を付けて保存し、ボタンで呼び出します。フェード時間を秒で付けられます。右クリックで、フェードの変更・現在の位置での上書き・削除ができます
- 記録するのは、パン/チルトを持つ全機材の `pan` と `tilt` だけです。光量や色は変更しません
- パッドには動作「位置プリセット」で割り当てます。OSC からは `/dmx/position 名前` で呼び出します
