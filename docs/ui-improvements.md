# UI 改善の方針

会場の準備は「機材」画面にまとめ、本番ではキーボードや MIDI から点灯・消灯、色、暗転をすぐに操作できるようにする。機材の状態は本番画面から確認できるようにする。

このメモは UI の修正がすべて終わり次第、削除する。

## 既存プロジェクトとの互換性

保存済みのシーン、プリセット、入力割り当て、機材とペアは、そのまま読み込めるようにする。初期割り当て案は新規設定や利用者が選んだ場合に適用する。画面の統合では既存の機材 ID とペアの参照を使う。ページ名や説明文などの保存項目を追加するときは既定値を用意し、保存形式を変更した版では旧ファイルの読み込みと再保存を確認する。数字キーが既に割り当てられている場合は、利用者がページ切替に指定するまで元の割り当てを使う。

## 変更の順序案

| 順序 | 変更 | 完了の目安 |
| --- | --- | --- |
| 1 | 暗転ボタンとキーボード・MIDI | 暗転中もボタンの位置とサイズが一定で、片手でページを切り替えられる。押した入力と実行される操作が画面で分かる |
| 2 | パッチとペアを「機材」に統合 | 一覧で機材を選び、アドレスの確認からグループ・ペアの設定まで同じ画面で行える |
| 3 | 初期設定と出力確認 | 同じ機材を選んだまま、位置や可動範囲の設定と、安全処理後の出力の確認ができる |
| 4 | 本番中の機材モニター | 演奏操作を隠さず、機材ごとの色・明るさと送信状態が分かる。会場配置の編集は一覧での試用後に判断する |

## 表示と入力

- 現在値、単位、固定値を、関連する入力欄の近くに表示する。
- 入力エラーでは、見直す項目と理由が分かるようにする。
- 確定前の入力は下書きとして扱い、検証してから設定に反映する。設定の変更には共通の編集処理を使い、実行中の演出操作は `LiveOp` を通す。
- ボタンのラベルが幅に収まらない場合は、普段は短い表示を使い、選択したボタンやフォーカス中のボタンで全文を横に流して繰り返し表示する。動きを減らす設定では、全文を静止した詳細欄で読めるようにする。狭い画面では操作欄を折り返し、フォーカスやエラーは色と文字で示す。[Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance)・[web.dev のモーション指針](https://web.dev/learn/accessibility/motion)

## MIDI とキーボードの演奏・編集

MIDI タブとキーボードタブには、演奏モードと編集モードの切替を設ける。現在のモードは切替欄に表示する。

- **演奏モード**では、パッドやキーを押すと、対応する画面上のボタンが反応し、割り当て済みの操作を実行する。
- **編集モード**では、パッドやキーの入力は割り当ての編集対象を選ぶためだけに使う。選んだボタンの割り当てを画面で変更できるようにする。
- キーボードタブ左側の説明文は、文字数の上限内で編集できるようにする。上限と現在の文字数を編集欄に表示する。具体的な上限は、表示領域を確認して決める。
- Shift キーを押し続ける操作は見直す。押し続けずに切り替えられ、現在の状態が画面で分かる方式を検討する。

## 割り当ての切替

既存のページ切替を使い、入力操作でキーボードと MIDI の割り当て一式を切り替える案を先に試す。キーボードは数字キーで直接選択、少ボタンの MIDI は任意のボタンに「次のページ」を割り当てる。数字キーの既存割り当てとの重複を確認し、説明文などの編集中は文字入力を優先する。画面にはページ名と切替後の割り当てを表示する。ページ切替時には、押したままの入力が解除され、切替先の操作が誤発火しないことを確かめる。[既存のページ操作](../src/live.rs)・[grandMA3 の Executor ページ](https://help.malighting.com/grandMA3/2.1/HTML/executor.html)

初期ページには、機材やグループの点灯・消灯、色、よく使うシーンを置く。操作頻度の低いムービングの動きは別ページに置く案とする。自動演出中に手動で色を変える場合は、上書き中と分かる表示と自動演出に戻る操作を用意する。どの入力をページ共通にするかは、少ボタンの機器で試して決める。[SoundSwitch の MIDI による手動上書き](https://www.soundswitch.com/software.html)

## 暗転ボタン

暗転の状態にかかわらず、ボタンの位置とサイズを一定にする。暗転の進み具合は、進捗ゲージのようにボタン内部の色が占める範囲を変えて表す。暗転中か復帰中かは、文字でも示す。

## 機材の状態表示

最初は機材名、色、明るさ、送信状態が分かる一覧を作り、本番画面から開ける折りたたみ式のパネルとして試す。画面で示すのは安全処理後の DMX 値から読み取れる状態で、現場での点灯は目視で照合する。向き、会場どおりの配置、オーバーレイは、一覧で本番中に確認しづらかった情報をもとに必要性を判断する。[ETC Eos の Magic Sheets](https://www.etcconnect.com/webdocs/Controls/EosFamilyOnlineHelp/en/Content/18_Magic_Sheets/About_Magic_Sheets.htm)・[grandMA3 の Layout View](https://help.malighting.com/grandMA3/2.5/HTML/layout_create.html)

## 機材の初期設定と動作確認

- パッチとペアを「機材」画面にまとめる。機材一覧に名前・型・ユニバース・開始アドレス・所属グループ・ペア相手を表示し、選んだ機材の詳細で調整する。ペアでは追従元、追従先、反転する項目を同時に確認できるようにする。[ETC Eos の Patch](https://www.etcconnect.com/webdocs/controls/iononlinehelp/en-us/content/05_Patch/05_Settings_in_Patch/Patch_Section.htm)・[現在のペア画面](../src/ui_pair.rs)
- レーザーの位置と大きさの調整を「機材」の詳細へ移す。対応機材に位置の数値入力を用意し、座標軸・単位・有効範囲を示す。「大きさ」は機材定義で何を制御しているかを確認して表示名を決める。パンの可動範囲やレーザーの安全設定は、同じ画面内の専用欄で扱う。機材定義や出力ポートなど、複数機材で共有する設定は詳細から参照できるようにする。
- 動作確認では、機材一覧からユニバース・開始アドレスと安全処理後の DMX 値を確認できるようにする。通常の照明を現場で照合する場合は、確認操作を開いてから対象を選び、前の機材のテスト点灯を解除して次に移れるようにする。既存の出力制限を適用し、レーザーは DMX 値の確認を対象にする。[ETC Eos の Channel Check](https://support.etcconnect.com/ETC/Consoles/Eos_Family/Software_and_Programming/How_to_Run_a_Channel_Check_on_Only_Patched_or_Used_Channels)

## 動作の確認

画面の変更は `DMXCTL_SHOT` で撮影し、文字や入力欄の見切れを確かめる。操作が DMX 値に関わる場合は、別の設定を使い、実機出力を止めた状態で CLI から安全処理後の値を確かめる。起動方法と確認手順は [開発ガイド](development.md) を参照する。
