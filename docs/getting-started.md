# 導入と最初の準備

## 導入方法

使うだけなら、ビルドは要りません。**[Releases](https://github.com/TechnoTUT/dmxctl/releases/latest)** から、使うPCに合ったファイルを落とします。

| PC | ファイル | 使い方 |
|---|---|---|
| Windows 10 / 11 | `dmxctl-windows-x86_64.exe` | ダブルクリックで起動します。exe 1つで動き、Visual C++ ランタイムなどのインストールは要りません |
| Mac | `DMX-Controller-mac.zip` | Apple Silicon と Intel の両方に対応します。展開して `DMX Controller.app` を「アプリケーション」へ入れ、初回は右クリック →「開く」で起動します。macOS 15 以降で開けないときは、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を押します |
| Linux | 普通のPCは `dmxctl-linux-x86_64`、Raspberry Pi 4/5 などは `dmxctl-linux-arm64` | Debian 12・Ubuntu 24.04 以降で動きます。`chmod +x` して実行します。デスクトップ環境が無い場合は自動で直接描画し、モニターが無い場合は `headless` を付けて起動します。詳しくは [Linux で使う](platforms.md#linux-で使う) |
| モニターの無いLinuxで常駐させる | 上と同じ `dmxctl-linux-x86_64` / `dmxctl-linux-arm64` | `./scripts/linux/install-headless.sh 落としたファイル` で導入すると、起動時に Beat Link Trigger と一緒に自動常駐します。`--no-blt` を付けると dmxctl だけになります。詳しくは [モニターの無いLinuxでオート](auto.md#モニターの無いlinuxでオート) |

- **Windows で「WindowsによってPCが保護されました」と出たとき**: 署名の無いアプリのため表示されます。「詳細情報」→「実行」で起動できます。Ableton Link・OSC・操作パネルの初回利用時は、ファイアウォールの確認で「許可」を押します
- 機材・割り当て・シーンなどの設定は、アプリとは別の場所に自動で保存されます。新しい版に入れ替えても、そのまま引き継がれます
- FT232系の USB-DMX は、Windows ならたいてい挿すだけで COM ポートとして使えます。詳しくは [USB-DMX について](platforms.md#usb-dmx-について)
- 新しい版は、Releases に `v0.2.0` のような番号で追加されます

## 最初の準備

1. **出力** タブで、USB-DMX か Art-Net の出力先を追加します
2. **パッチ** タブで、機材のアドレスを実機の DIPスイッチやメニューの設定と合わせます。手持ちの機材が内蔵の定義に無ければ **機材定義** タブで作ります
3. **MIDI** タブの「配置」メニューから **おすすめ配置** を選ぶと、APC mini mk2 とキーボードの割り当てが今の機材に合わせてまとめて作られます。既存のAPCの割り当ては置き換わりますが、元の状態はバックアップに残ります
4. ムービングがあれば、**キーボード** タブの「向き合わせ」で、真上と正面を1回合わせます。詳しくは [ムービングの動き](operation.md#ムービングの動き)
5. レーザーがあれば、**レーザー** タブで「動いてよい範囲」を決めておきます。詳しくは [レーザー](operation.md#レーザー)

**タブの使い分け**

| タブ | 使うとき |
|---|---|
| MIDI | 本番のメイン画面。APC mini mk2 と同じ配置の図で、割り当てと今の状態を見る・変える |
| キーボード | MIDIコントローラーが無いとき。キーボードの絵に割り当てが出る。BPMと色のプレビュー、ムービングの向き合わせもここ |
| コントロール | 機材を1台ずつ手で操作する。XYパッド・位置プリセットもここ |
| エフェクト / シーン / BPM/チェイス / ペア | 演出を作る |
| レーザー | レーザーの位置・大きさ・動いてよい範囲をマウスだけで決める |
| パッチ / 機材定義 / 出力 / MIDI設定 | 準備・設定 |
| モニター | 実際に送っているDMXの値を見る |

## 設定の保存場所

設定は自動で保存されます。保存場所は次のとおりで、中身はどのOSでも同じ形式です。

| OS | 場所 |
|---|---|
| Windows | `%APPDATA%\dmxctl\` |
| Mac | `~/Library/Application Support/dmxctl/` |
| Linux | `~/.config/dmxctl/`。`XDG_CONFIG_HOME` があればその下 |

## バックアップ

- 起動時と別のファイルを開く前に、設定フォルダの `backups/project-日付-時刻.json` へ最新20件まで自動保存します
- 「ファイル」メニューの「**バックアップから戻す**」で、選んだものに戻せます。戻す前の状態もバックアップされるため、やり直せます
- 5秒ごとに自動保存されるため、誤って消した割り当てやシーンが保存されても、起動時の状態まで戻せます
- **新しい版で保存したファイル**を古い版で開くと、未対応の項目だけを既定値にして起動し、飛ばした項目を通知します。割り当てなら該当の1件だけを飛ばします。元のファイルは `project.broken-数字.json` に残ります

## 設定を別のPCへ移す

設定フォルダの中身を新しいPCの同じ場所へコピーします。本体は `project.json` と `fixtures/` で、`backups/` は不要です。

移したあとは、次を選び直します。

- 「出力」タブで、USB-DMX のポート名を選び直します。Mac では `/dev/cu.usbserial-…`、Windows では `COM3`、Linux では `/dev/ttyUSB0` のような名前です
- 2ページ目の設定パネルで、NDI のソースを選び直します。ソース名にPC名が入るためです
- 初めてネットワークを使うときに出る確認は「許可」を押します。Mac では「ローカルネットワーク」、Windows ではファイアウォールの確認です
