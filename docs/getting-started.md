# 導入と最初の準備

## 導入方法

利用するだけであれば、ビルドは不要です。**[Releases](https://github.com/TechnoTUT/dmxctl/releases/latest)** から、利用するPCに合ったファイルをダウンロードします。

| PC | ファイル | 利用方法 |
|---|---|---|
| Windows 10 / 11 | `dmxctl-windows-x86_64.exe` | ダブルクリックで起動します。exe 1つで動作し、Visual C++ ランタイムなどの導入は不要です |
| Mac | `DMX-Controller-mac.zip` | Apple Silicon と Intel の両方に対応します。展開して `DMX Controller.app` を「アプリケーション」へ配置し、初回は右クリック →「開く」で起動します。macOS 15 以降で開けないときは、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を押します |
| Linux | 通常のPCは `dmxctl-linux-x86_64`、Raspberry Pi 4/5 などは `dmxctl-linux-arm64` | Debian 12・Ubuntu 24.04 以降で動作します。`chmod +x` で実行権限を付与して起動します。デスクトップ環境が無い場合は画面に直接描画し、モニターが無い場合は `headless` を付けて起動します。詳しくは [Linux で使う](platforms.md#linux-で使う) |
| モニターの無い Linux で常駐させる | 上と同じ `dmxctl-linux-x86_64` / `dmxctl-linux-arm64` | `./scripts/linux/install-headless.sh 取得したファイル` で導入すると、起動時に Beat Link Trigger と一緒に自動で常駐します。`--no-blt` を付けると dmxctl だけになります。詳しくは [モニターの無い Linux でオート](auto.md#モニターの無いlinuxでオート) |

- **Windows で「WindowsによってPCが保護されました」と表示されたとき**: 署名の無いアプリのため表示されます。「詳細情報」→「実行」で起動できます。Ableton Link・OSC・操作パネルの初回利用時は、ファイアウォールの確認で「許可」を押します
- 機材・割り当て・シーンなどの設定は、アプリとは別の場所に自動で保存されます。新しい版に入れ替えても、そのまま引き継がれます
- FT232系の USB-DMX は、Windows であれば通常は接続するだけで COMポートとして利用できます。詳しくは [USB-DMX について](platforms.md#usb-dmx-について)
- 新しい版は、Releases に `v0.2.0` のような番号で追加されます

## 最初の準備

1. **出力** タブで、USB-DMX か Art-Net・sACN の出力先を追加します。sACN は送り先を空にするとマルチキャスト(239.255.x.y)で送信し、ユニバースは 1〜63999、優先度の標準は 100 です
2. **パッチ** タブで、機材のアドレスを実機の DIPスイッチやメニューの設定と一致させます。手持ちの機材が内蔵の定義に無ければ **機材定義** タブで作成します。使わない機材は「削除」で削除できます。その機材だけを対象にした割り当てとエフェクトも一緒に削除されます
3. **MIDI** タブの「配置」メニューから **おすすめ配置** を選ぶと、APC mini mk2 とキーボードの割り当てが現在の機材に合わせて一括で作成されます。既存の APC の割り当ては置き換わりますが、元の状態はバックアップに残ります
4. ムービングがあれば、**キーボード** タブの「向き合わせ」で、真上と正面を1回合わせます。詳しくは [ムービングの動き](operation.md#ムービングの動き)
5. レーザーがあれば、**レーザー** タブで「動いてよい範囲」を設定しておきます。詳しくは [レーザー](operation.md#レーザー)

**タブの使い分け**

| タブ | 利用する場面 |
|---|---|
| MIDI | 本番のメイン画面。APC mini mk2 と同じ配置の図で、割り当てと現在の状態を確認・変更する |
| キーボード | MIDIコントローラーが無いとき。キーボードの図に割り当てが表示される。BPMと色のプレビュー、ムービングの向き合わせもここ |
| コントロール | 機材を1台ずつ手動で操作する。XYパッド・位置プリセットもここ |
| エフェクト / シーン / BPM/チェイス / ペア | 演出を作成する |
| レーザー | レーザーの位置・大きさ・動いてよい範囲をマウスだけで設定する |
| パッチ / 機材定義 / 出力 / MIDI設定 | 準備・設定 |
| モニター | 実際に送信している DMX の値を確認する |

## 設定の保存場所

設定は自動で保存されます。保存場所は次のとおりで、中身はどの OS でも同一の形式です。

| OS | 場所 |
|---|---|
| Windows | `%APPDATA%\dmxctl\` |
| Mac | `~/Library/Application Support/dmxctl/` |
| Linux | `~/.config/dmxctl/`。`XDG_CONFIG_HOME` が設定されていればその下 |

## バックアップ

- 起動時と別のファイルを開く前に、設定フォルダの `backups/project-日付-時刻.json` へ最新20件まで自動保存します
- 「ファイル」メニューの「**バックアップから戻す**」で、選択した時点の状態に復元できます。復元前の状態もバックアップされるため、やり直しが可能です
- 5秒ごとに自動保存されるため、誤って削除した割り当てやシーンが保存されても、起動時の状態まで復元できます
- **新しい版で保存したファイル**を古い版で開くと、未対応の項目だけを既定値にして起動し、読み込めなかった項目を通知します。割り当てなら該当の1件だけを除外します。元のファイルは `project.broken-数字.json` に残ります

## 設定を別のPCへ移す

設定フォルダの中身を新しいPCの同じ場所へコピーします。本体は `project.json` と `fixtures/` で、`backups/` は不要です。

移行後は、次の項目を選び直してください。

- 「出力」タブで、USB-DMX のポート名を選び直します。Mac では `/dev/cu.usbserial-…`、Windows では `COM3`、Linux では `/dev/ttyUSB0` のような名前です
- 2ページ目の設定パネルで、NDI のソースを選び直します。ソース名に PC 名が含まれるためです
- 初めてネットワークを利用するときに表示される確認は「許可」を押します。Mac では「ローカルネットワーク」、Windows ではファイアウォールの確認です
