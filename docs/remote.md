# スマホ・別のPCから操作する

## スマホから操作する

dmxctl が動作している PC に、同じネットワークにあるスマホや PC のブラウザでアクセスすると、操作パネルが表示されます。アプリを導入する必要はありません。

```
http://このPCのIPアドレス:8080/
```

- **`dmxctl headless` では操作パネルが常に有効で**、起動ログに `操作パネル: http://192.168.x.x:8080/` のようにアドレスが表示されます
- 画面のある PC では、「MIDI設定」タブの「スマホから操作(操作パネル)」を ON にします。ポートと合言葉もここで設定します。ON にすると、開くアドレスが横に表示されます

| パネルでできること | |
|---|---|
| 様子 | オートの状態、BPM、Link の台数、フレーズ、出力のエラー。オートの状態は 受信中 / 待機 / 手動優先 のどれか。BLT が見つからないときは一番上に警告が表示される |
| 基本 | BLACKOUT、暗転、押下中のみ有効な FLASH、全体光量、TAP、頭出し |
| オート | ON/OFF、プリセットの切り替え、フレーズの見た目を試す、「オートに戻す」 |
| 色 | メイン色・サブ色の選択、入れ替え。選択すると、しばらくオートより優先する手動優先になる |
| シーン | シーンを呼び出す。これも手動優先になる |

- 1秒ごとに様子を読み直します。複数のスマホから同時に開いても問題ありません
- **合言葉**: 設定すると接続時に合言葉を求め、入力内容はブラウザに保存されます。空の場合は同じネットワークの誰でも操作できるため、人の出入りが多い環境では設定を推奨します
- 通信は http で暗号化しないため、合言葉は照明のいたずら防止程度と考えてください。既定のポート 8080 は、ファイアウォールで開放しておきます

## 別のPCの画面から操作する

照明を出力する PC をサーバーにして、別の PC をクライアントにすると、クライアントの画面と MIDI コントローラーで操作できます。DMX の送出・Ableton Link・OSC・NDI・オートはサーバーが動作し続けるため、操作する PC を閉じたり付け替えたりしても照明は停止しません。

1. サーバーで、`--remote-listen` にサーバーの PC のアドレスを付けて起動します。画面があってもなくても構いません

   ```
   dmxctl headless --remote-listen 192.168.1.10
   ```

   照明用の LAN のアドレスを指定すると、その LAN からだけ接続できます。ポートの既定は 9300 で、`192.168.1.10:9400` のように変更できます。どのネットワークからでも受け付けるなら `0.0.0.0` を指定します

   画面のある PC では、起動後に「MIDI設定」タブの「別のPCから操作する」でも開始できます。アドレスとポートを確認して「待ち受ける」を ON にすると、右に接続先が表示されます。この設定は保存しないため、起動のたびに OFF に戻ります。安全の設定の変更は、この方法では許可できません。許可するときは `--remote-allow-safety-edit` を付けて起動します

2. 操作する PC で、サーバーのアドレスを指定して起動します

   ```
   dmxctl connect 192.168.x.x
   ```

   画面は通常どおりです。画面の下に、サーバーとの接続状態が表示されます。切断されても自動で再接続します

   引数を付けて起動しづらい Windows や Mac では、通常どおり起動して、ファイルメニューの「サーバーに接続…」にサーバーのアドレスを入力します。接続できると確認してから、この PC の画面を閉じて、クライアントとして起動し直します。接続の前に、この PC の照明の出力は止まります。通常の起動へ戻すときは、ファイルメニューの「サーバーから切断して通常起動に戻す」を選択します。起動時の `--project` などの引数は引き継ぎます。デスクトップ環境の無い `kmsdrm` では、この項目を表示しません

- APC mini などの **MIDIコントローラー** は、操作する PC に接続します。押した内容はサーバーへ送信され、パッドの LED はサーバーの状態で点灯します
- パッチ・割り当て・シーン・出力・OSC などの **設定の変更** は、操作する PC の画面からそのまま行えます。変更はサーバーに送信され、接続している他の PC にも反映されます
- 出力の COMポート・USB-DMX、音声の入力、MIDI クロックの入力は、**サーバーの PC の機器** の一覧から選択します。実際に開くのはサーバーだからです。「一覧を更新」「再検出」で、サーバー側で再取得できます
- **機材定義** の保存・削除は、サーバーの機材定義フォルダに書き込みます。
- **安全の設定** は、通常はサーバーの PC の画面でのみ変更できます。対象は、機材定義の安全な値と ARM が必要かどうか、レーザーなどの動いてよい範囲、保護された機材(レーザー・範囲や禁止値のある機材)のパッチ・削除・有効状態と、そのアドレスへの別の機材の重ね置き、ムービングの向きの校正、ARM とレーザーの合図の割り当てです。操作する PC の画面から変えようとすると、理由を表示して取り消します。操作する PC からプロジェクトを開くときも、安全の設定が変わるファイルは開けません。画面の無いサーバーで変更するときは、サーバーを `--remote-allow-safety-edit` も付けて起動し直すと、操作する PC の画面から変更できます。変更後は、このオプションを付けずに起動し直してください
- **保存** はサーバーで行います。操作する PC で Ctrl+S を押しても、サーバーに保存を依頼します
- **別のファイルを開く** ときは、ファイルメニューから次のいずれかを選択します
  - 「サーバーのファイルを開く」: サーバーのプロジェクトのフォルダにある .json を開きます
  - 「サーバーのバックアップから戻す」
  - 「このPCのファイルを開く…」: 操作する PC にあるファイルの中身を、サーバーへ送信します

  通常の「開く」と同様に中身を読み込むだけで、保存先は変わりません。読み込み前の状態はサーバーのバックアップに残ります
- 操作する PC を終了しても、照明はそのままで、ブラックアウトしません
- 押下中のみ有効なパッドやキーを押したまま接続が切断されたときは、サーバーが解放したものとして扱います。フラッシュなどが点灯したままになりません
- 切断中の画面の編集はサーバーに届きません。画面の下にその旨が表示され、再接続するとサーバーの内容に戻ります
- 16台までの PC から同時に接続できます。他の PC が先に変更した項目や、追加・削除で位置がずれた一覧への編集は、取り消して画面の下に通知します
- 通信は暗号化も認証も行いません。照明用の有線 LAN など、**信頼できる機器だけが接続するネットワーク** で利用してください。既定のポート 9300 は、ファイアウォールで開放しておきます
