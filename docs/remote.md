# スマホ・別のPCから操作する

## スマホから操作する

dmxctl が動いているPCに、同じネットワークにあるスマホやPCのブラウザでアクセスすると、操作パネルが出ます。アプリを入れる必要はありません。

```
http://このPCのIPアドレス:8080/
```

- **`dmxctl headless` では操作パネルが常に有効で**、起動ログに `操作パネル: http://192.168.x.x:8080/` のようにアドレスが出ます
- 画面のあるPCでは、「MIDI設定」タブの「スマホから操作(操作パネル)」をONにします。ポートと合言葉もここで決めます。ONにすると、開くアドレスが横に出ます

| パネルでできること | |
|---|---|
| 様子 | オートの状態、BPM、Link の台数、フレーズ、出力のエラー。オートの状態は 受信中 / 待機 / 手動優先 のどれか。BLT が見つからないときは一番上に警告が出る |
| 基本 | BLACKOUT、暗転、押している間の FLASH、全体光量、TAP、頭出し |
| オート | ON/OFF、プリセットの切り替え、フレーズの見た目を試す、「オートに戻す」 |
| 色 | メイン色・サブ色を選ぶ、入れ替え。選ぶと、しばらくオートより優先する手動優先になる |
| シーン | シーンを呼び出す。これも手動優先になる |

- 1秒ごとに様子を読み直します。複数のスマホから同時に開いても大丈夫です
- **合言葉**: 設定すると接続時に合言葉を求め、入力内容はブラウザに保存されます。空なら同じネットワークの誰でも操作できるため、人が多い環境では設定を推奨します
- 通信は http で暗号化しないので、合言葉は照明のいたずら防止くらいのものと考えてください。既定のポート 8080 は、ファイアウォールで開けておきます

## 別のPCの画面から操作する

照明を出すPCをサーバーにして、別のPCをクライアントにすると、クライアントの画面とMIDIコントローラーで操作できます。DMXの送出・Ableton Link・OSC・NDI・オートはサーバーが動かし続けるので、操作するPCを閉じたり付け替えたりしても照明は止まりません。

1. サーバーで、`--remote-listen` にサーバーのPCのアドレスを付けて起動します。画面があってもなくてもかまいません

   ```
   dmxctl headless --remote-listen 192.168.1.10
   ```

   照明用のLANのアドレスを指定すると、そのLANからだけつなげます。ポートの既定は 9300 で、`192.168.1.10:9400` のように変えられます。どのネットワークからでも受けるなら `0.0.0.0` を指定します

2. 操作するPCで、サーバーのアドレスを指定して起動します

   ```
   dmxctl connect 192.168.x.x
   ```

   画面はふだんと同じです。画面の下に、サーバーとの接続の状態が出ます。切れても自動でつなぎ直します

- APC mini などの **MIDIコントローラー** は、操作するPCにつなぎます。押した内容はサーバーへ送られ、パッドのLEDはサーバーの状態で光ります
- パッチ・割り当て・シーン・出力・OSC などの **設定の変更** は、操作するPCの画面からそのままできます。変更はサーバーに送られ、つないでいるほかのPCにも反映されます
- 出力の COMポート・USB-DMX、音声の入力、MIDIクロックの入力は、**サーバーのPCの機器** の一覧から選びます。実際に開くのはサーバーだからです。「一覧を更新」「再検出」で、サーバーに調べ直してもらえます
- **機材定義** の保存・削除は、サーバーの機材定義のフォルダに書き込みます。レーザーなどの安全の設定、つまり安全な値と ARM が要るかどうかは、ふだんはサーバーのPCの画面でだけ変えられます。画面の無いサーバーで変えるときは、サーバーを `--remote-allow-safety-edit` も付けて起動し直すと、操作するPCの画面から変えられます。変え終わったら、付けずに起動し直してください
- **保存** はサーバーで行います。操作するPCで Ctrl+S を押しても、サーバーに保存を頼みます
- **別のファイルを開く** ときは、ファイルメニューから次のどれかを選びます
  - 「サーバーのファイルを開く」: サーバーのプロジェクトのフォルダにある .json を開きます
  - 「サーバーのバックアップから戻す」
  - 「このPCのファイルを開く…」: 操作するPCにあるファイルの中身を、サーバーへ送ります

  通常の「開く」と同様に中身を読み込むだけで保存先は変わらず、読み込み前の状態はサーバーのバックアップに残ります
- 操作するPCを終了しても、照明はそのままで、ブラックアウトしません
- 押している間だけ効くパッドやキーを押したまま接続が切れたときは、サーバーが離したことにします。フラッシュなどがつきっぱなしになりません
- 切れているあいだの画面の編集はサーバーに届きません。画面の下にそのことが出て、つなぎ直すとサーバーの内容に戻ります
- 16台までのPCから同時につなげます。ほかのPCが先に変えた項目や、追加・削除で位置がずれた一覧への編集は、取り消して画面の下に知らせます
- 通信は暗号化も認証もしません。照明用の有線LANなど、**信頼できる機器だけがつながるネットワーク** で使ってください。既定のポート 9300 は、ファイアウォールで開けておきます
